# Trick Or Treat

A spooky trick-or-treating game that runs entirely in the browser — one `index.html`, no install, no build step.

- Build a costume from premade looks or custom parts, then hit a new randomly generated street every night.
- Impress the neighbors for candy. Disappoint them and get tricked: stolen candy, mini-games, or a dog chasing you down the block.
- Nine haunted houses, each with its own monster. Some of them are not what they seem.
- Night events, goals, unlockable costume parts, an encounters journal and saved outfits. Progress is saved in your browser.
- Works on computers (keyboard + mouse) and phones (touch, auto-landscape).

⚠ Contains loud jump scares and flashing images. A milder Terror setting is on the main menu.

## Play

Open `index.html` in any modern browser, or play the hosted version on GitHub Pages.
